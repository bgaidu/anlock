## 通读项目（KidsLock 儿童锁屏）

- 项目：Android TV/平板儿童锁屏「认字解锁」，纯 Java，AGP 8.2.0 / Gradle 8.5，
  minSdk 21 / targetSdk 33 / compileSdk 34，versionName 1.2（versionCode 3）。
- 8 个 Java 类约 2300 行：MainActivity（设置页+家长PIN门禁）、LockScreenActivity（答题/解锁）、
  LockService（计时+看门狗+悬浮窗+闹钟）、PrefManager（持久化+计时对账+PIN哈希）、
  CharacterBank（144 条五年级汉字硬编码）、RecoveryAccessibilityService（无障碍守护）、
  BootReceiver、AlarmReceiver。
- 四层防绕过：悬浮窗拦截 / AlarmManager 到期闹钟 / 界面自愈 / 无障碍守护（开机自启兜底）。

### 关键事实（踩过的坑，别重复排查）
- **JDK 必须 17**。系统 PATH 原本无 java；PyCharm 自带 JBR 是 JDK 25，Gradle 8.5 / AGP 8.2 不支持。
  JDK 17 解压在 `.workbuddy/tools/jdk17`（304MB，已被 .gitignore 的 `/.workbuddy/tools/` 忽略）。
- **SDK 不在仓库里**：`/android-sdk/` 是仓库原有 ignore 规则，`git ls-files android-sdk` 为 0。
  本机 SDK 在 `D:/soft/myapp/kidslock/android-sdk`（android-34 + build-tools 34.0.0 + platform-tools）。
  local.properties 已改为 `sdk.dir=D:/soft/myapp/kidslock/android-sdk`；ANDROID_HOME 兜底也可用。
- **网络只能走本地代理 127.0.0.1:54260**，且 JVM 不读 http_proxy 环境变量，Gradle 必须显式配。
  代理写在**用户级** `C:/Users/mytest/.gradle/gradle.properties`（仓库外，不污染项目）。
- **Adoptium 官方 API 在本机 502**（302 跳 GitHub，代理访问不了），JDK 是从清华镜像下载的。
- `gradle.properties` 的 `android.overridePathCheck=true` 是必需的（SDK 在项目目录内），别删。

### 关键技术约束（实施时必须遵守）
- **干扰项绝不能用占位文本**：占位项一眼可辨，会把 4 选 1 降成 3 选 1，破坏解锁难度设计。
  拼音干扰项从同池取；数学按典型错误构造（±1、进退位错、符号错）。
- **至少启用一个科目是安全红线**，三层防护：UI 拒绝取消最后一个 / 存储层拒绝写空 Set / 出题层强制回退拼音。
- **拼音五年级字表必须与现有 CharacterBank 的 144 条一字不差**（升级兼容底线）。
- **JSON 解析用 Android 自带 org.json，零新增依赖**（不要引 Gson/Moshi）。
- **科目数必须配置驱动**，不得硬编码为 2（下期加英语不用改逻辑）。
- **选中态不要复用 `btn_settings_bg`**：它是三态 selector 且 `state_focused` 排首位，会盖掉
  `state_selected`，聚焦时选中态不可见 → 改用文字通道（选中 `✓数学` + correct_green）。
- TV 遥控器只有方向键+确认键，科目多选用「焦点移动 + 确认键 toggle」，不能用 CheckBox。
- **不动计时与防绕过逻辑**（PrefManager 计时对账 / LockService / 无障碍守护 / 两个 Receiver）。

### 2026-10-12 补充：release 构建实测（已验证）

  JAVA_HOME**，每条构建命令需先 `export JAVA_HOME=/d/soft/myapp/kidslock/.workbuddy/tools/jdk17 &&

  走代理 127.0.0.1:54260；代理关闭时该步 `Connection refused`。离线跳过 lint 的命令：
  `KEYSTORE_*=… ./gradlew assembleRelease -x lintVitalAnalyzeRelease -x lintVitalRelease --offline`。
- release keystore 密码已验证可用（alias kidslock，PKCS12，明文不入库）。签名产物
  `app/build/outputs/apk/release/app-universal-release.apk`（CN=KidsLock，SHA1 B1:1B:C6:90…，
  有效期至 2054-02-18）。三个 ABI 分包大小相同（纯 Java 无 .so），无害。
- keystore 文件位于仓库外的 `D:/soft/myapp/kidslock-release.keystore`，本就不受 git 跟踪。
