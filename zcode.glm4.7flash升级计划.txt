### 任务 2.2：答题正确率统计
**优先级**：P1 | **工作量**：1.5天 | **依赖**：2.1

#### 具体步骤
1. 创建 `StatsManager.java`：
   ```java
   public class StatsManager {
       // 每科统计数据
       private Map<String, SubjectStats> stats = new HashMap<>();
       
       // 更新正确率
       public void recordAnswer(String subject, boolean correct) {
           SubjectStats s = stats.computeIfAbsent(subject, k -> new SubjectStats());
           s.totalAnswers++;
           if (correct) s.correctAnswers++;
       }
       
       // 获取正确率
       public double getAccuracy(String subject) {
           SubjectStats s = stats.get(subject);
           return s == null ? 0 : (double) s.correctAnswers / s.totalAnswers;
       }
   }
   ```

2. 在 `LockScreenActivity` 中记录答题：
   ```java
   private StatsManager stats;
   
   public void onOptionClicked(int index, String option) {
       boolean correct = currentQuestion.getAnswer() == index;
       stats.recordAnswer(currentQuestion.getSubject(), correct);
       
       if (correct) {
           correctCount++;
           questionEngine.adjustDifficultyBasedOnPerformance(correctCount);
       }
   }
   ```

3. 创建统计界面：

2. 使用对象池：
   ```java
   public class QuestionPool {
       private static final int POOL_SIZE = 10;
       private Queue<Question> pool = new LinkedList<>();
       
       public Question acquire() {
           return pool.poll() != null ? pool.poll() : new Question();
       }
       
       public void release(Question q) {
           pool.offer(q);
       }
   }
   ```
