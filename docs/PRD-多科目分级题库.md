## 1. 产品目标

**一句话**：让家长按孩子的真实年级与已学科目配置解锁题，在**不降低防绕过强度**的前提下，把难度调到"孩子跳一跳够得着"的位置。

### 成功标准（可验收）

| # | 标准 |
|---|---|
| S1 | 家长仅用遥控器**方向键 + 确认键**即可完成年级与科目的全部配置，全程不需要键盘/鼠标/文本输入 |
| S2 | 老用户升级后：若从未改过年级/科目/题数（存储值恰为旧默认 5 / pinyin / 3），经 `migrateLegacyDefaults()` **一次性迁移**到新默认（年级 3 / 科目 pinyin,math / 题数 5），与全新安装体验一致；若曾自定义则原样保留，防护不被削弱 |
| S3 | 任何配置组合（含 SharedPreferences 被外部篡改的脏数据）下都**不会出现"无题可出"**，最坏情况退化为拼音科目出题；锁屏界面绝不空转，孩子绝不会被无限锁死（**D4**：为此可接受兜底路径上的偶发超纲） |
| S4 | 本期两个科目（拼音 / 数学）的干扰项均"像答案"——不存在占位文本、数量级明显不符的异常值、或可一眼排除的选项 |
| S5 | 全部拼音字表资产合计 < 1 MB，APK 体积无可感知变化 |

### 非目标（本期不做）

- 英语 TTS 发音（英语题型本身已落地，见 R10 / R20）
- 家长自定义导入题库
- 答题正确率统计与自动调难度
- 题目难度在答题过程中动态浮动（难度只由家长设定值决定，不随答题表现变化）

## 2. 用户故事

### 2.1 家长

| # | 用户故事 |
|---|---|
| US-P1 | 作为**家长**，我希望按孩子的实际年级（学前 ~ 六年级）设定出题难度，以便题目落在孩子课堂学过的范围内，而不是超纲的偏字偏词。 |
| US-P2 | 作为**家长**，我希望按孩子已学科目勾选出题范围（**拼音 / 数学**，可多选），以便把题目限定在孩子学得会的范围内。 |
| US-P3 | 作为**家长**，我希望配置只用遥控器方向键和确认键就能完成，以便我在电视前不用找鼠标键盘也能改设置。 |
| US-P4 | 作为**家长**，我希望当我试图关掉最后一个科目时，系统明确拒绝并告诉我原因，以便我不会误操作导致孩子面对无法作答的界面。 |
| US-P5 | 作为**家长**，我希望升级应用后原有设置和出题难度不变，以便不必重配一次，也不会因为默认变简单而让防护形同虚设。（**D6 例外**：默认基线由五年级/仅拼音改为三年级/拼音+数学，且对"从未改过"的存量用户做一次性迁移；已自定义的用户原样保留） |
| US-P6 | 作为**家长**，我希望在设置页能一眼看到当前生效的年级与科目，以便确认改动真的保存了（遥控器操作缺少即时反馈容易不确定）。 |

### 2.2 孩子（诉求与家长天然对立，明确记录）

| # | 用户故事 |
|---|---|
| US-C1 | 作为**孩子**，我希望题目越简单越好、我一眼就能认出，以便最快答完解锁继续看。 |
| US-C2 | 作为**孩子**，我希望选项里有明显不是答案的项，以便靠排除法快速蒙对。 |
| US-C3 | 作为**孩子**，我希望只出我会的那一个科目，以便不用面对没学过的内容。 |
| US-C4 | 作为**孩子**，我希望出题顺序可预测（比如总是同一个字），以便我练熟就能秒过。 |

### 2.3 产品立场（明确写死，供架构师/工程师取舍时引用）

US-C1 ~ US-C4 是孩子的真实诉求，**但本产品不为它们做任何优化**。设计上只承诺两件事：

1. **难度对家长可控**：家长想让题简单，自己把年级调低即可，产品不代劳、不自动放水。
2. **绝不提供可辨识的送分路径**：不使用占位选项、不使用明显异常值、不固定正确选项位置、不固定出题顺序。

孩子的诉求由家长的设置权代表。当"降低难度"与"保持防绕过强度"冲突时，**默认取后者**，并把选择权以显式设置项的形式交给家长。

| R07 | P0 | **通用题目结构**：本期**拼音 / 数学 / 英语 / 语文 4 个科目共用**一套题目模型 | 提供 `Question`，至少包含：题干文本、4 个选项文本、正确选项索引（0~3）、科目标识。`LockScreenActivity` 只依赖 `Question` 渲染，不含任何科目分支逻辑（该结构对下期英语可扩展，无需改造） |

| R09 | P0 | **数学题型**：代码生成，题干形如 `7 + 8 = ?`，4 个数字选项 | ① 按 R09-表 的年级参数表出题，**参数范围写死、不随运行时浮动**；② 干扰项按"典型错误"优先级构造（见 R09-表），凑不满 3 个时才用同量级随机值补；③ 通用约束：除法必须整除；学前~二年级不出负数、不出小数；结果必须是整数或 ≤2 位有限小数；④ 4 个选项互不相同、均不等于正确值；⑤ 正确项位置随机，不固定；⑥ 干扰项**不得**出现与本量级明显不符的异常值（其余选项均为两位数时，不得混入个位数或三位数选项），也不得出现 0 / 负数占位 |

**R09-表：数学出题参数（按年级，写死）**

| 年级编码 | 年级 | 题型 | 参数约束 | 干扰项构造（按优先级取，凑满 3 个） |
|---|---|---|---|---|
| 0 | 学前 | 10 以内加法、10 以内减法 | `a,b ∈ [1,9]`；加法 `a+b ≤ 10`；减法 `a > b` 且结果 ≥ 1 | ① 正确值 ±1；② 运算符号用反的结果（`a-b` 给 `a+b`）；③ 与正确值同量级的其他随机值 |
| 1 | 一年级 | 20 以内加减（含进退位） | `a,b ∈ [1,19]`；加法 `a+b ≤ 20`；减法 `a ≥ b` | ① ±1；② 进退位错误结果（如 `15−8` 给 `13`）；③ ±10；④ 符号用反 |
| 2 | 二年级 | 表内乘法（九九表）、100 以内加减 | 乘法 `a,b ∈ [2,9]`；加减 `a,b ∈ [1,99]`，结果 ≥ 1 | ① ±1；② 口诀邻位干扰（`7×8` 给 `54`，即 `6×9`）；③ ±10；④ 用错运算 |
| 3 | 三年级 | 表内乘除、两步加减 | 乘法 `a,b ∈ [2,12]`；除法 被除数 ≤ 144、除数 ∈ [2,12]、整除；两步 `(a±b)±c`，各步中间值 ∈ [1,100] | ① ±1；② 积/商 ±1；③ 运算顺序错误结果（先算后一项）；④ ±10 |
| 4 | 四年级 | 两步四则混合（含一层括号）、两位数 × 一位数 | 中间结果 ≤ 1000，结果 ≥ 1 | ① 运算顺序错误结果；② ±1；③ 位值错误（`23×4` 给 `82`）；④ ±10 |

```
⑦b tvQuestionSubjects + [拼音][数学][英语][语文]        ← 新增，4 项多选 toggle（环形焦点链）
⑧ btnGuardStatus
```

理由：⑦ 与 ⑦a/⑦b 同属"解锁考核"语义（答几道 / 什么难度 / 什么科目），物理相邻最符合家长的心智顺序；放在 ⑧ 之后会被守护服务、PIN 等运维项打断。

### 4.3 科目选择器（2 项多选，遥控器可行方案）

> **D3 修订**：本期科目为 `拼音` `数学` `英语` 三项，交互与选中态设计不变（复用按钮组 + 文字通道）。

**关键约束**：TV 遥控器只有方向键 + 确认键，**没有鼠标勾选能力**。因此**不使用 `CheckBox` / `Switch`**（既无法用遥控器勾选，也与现有按钮组风格割裂）。

| 选中反馈 | 选中：`✓拼音`，文字 `@color/correct_green`；未选中：`拼音`，文字 `@color/btn_text`。`tvQuestionSubjects` 显示 `科目：拼音、数学、英语`（按 `Subject.ORDER` 顺序罗列启用项） |

### 4.4 为什么选中态用"文字 + 颜色"而不是背景

现有 `@drawable/btn_settings_bg` 是三态 selector，`state_focused` 排在首位：

```
state_focused=true → 蓝灰填充 + highlight 描边
state_pressed=true → 蓝灰填充
(默认)            → 深蓝填充 + 细描边
```

若在其中新增 `state_selected` 项，因为 selector **按声明顺序取第一个匹配项**，聚焦时会命中 `state_focused` 而覆盖掉 `state_selected`——选中态在焦点停留时不可见，遥控器操作下等于失效。

因此选中态改走**文字通道**：`✓` 前缀 + `@color/correct_green`，与焦点的背景高亮并行不悖；同时由 `tvQuestionGrade` / `tvQuestionSubjects` 两个 `TextView` 提供不依赖焦点的权威显示（与 `tvWatchTime`「观看时长：30 分钟」、 `tvUnlockCount`「解锁题数：3 道连续答对」的现有句式一致）。

> 若工程师希望额外做背景区分，需新建 `btn_settings_toggle_bg.xml` 并把 `state_selected` 声明在 `state_focused` **之前**——但这会弱化焦点反馈，TV 上得不偿失，**不建议**。
