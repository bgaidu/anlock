## 2. 项目概览

**KidsLock（儿童锁屏 · 答题解锁）**：一款面向 **Android TV / 平板** 的儿童锁屏应用。按家长设定的"亮屏时长"自动锁屏，孩子必须连续答对指定数量题目（按年级 + 科目出题）才能解锁；家长可用 4 位 PIN 随时解锁。

- **形态**：Android 应用（手机/平板/电视均可安装，同时声明 `LAUNCHER` 与 `LEANBACK_LAUNCHER`）
- **语言**：**纯 Kotlin 1.9.0**（已从 Java 全量迁移，仅剩 3 个单测文件为 Java，属有意为之的混合源码）
- **最低/目标/编译**：minSdk 21 / targetSdk 33 / compileSdk 34
- **包名**：`com.kidslock.app`
- **版本**：versionCode 29 / versionName `1.0.1.26`
- **发布渠道**：GitHub Actions（`build.yml`，推送 `v*` 标签触发），密钥库经 `secrets.KEYSTORE_BASE64` 还原
- **无后端、无第三方在线服务**：完全离线运行，所有题目本地生成或从内置/导入题库读取

## 5. 技术方案 / 架构设计

### 5.1 总体架构

```
UI 层
  MainActivity(设置/PIN门禁)  LockScreenActivity(锁屏答题)  QuestionPreviewActivity(预览)
        │                              │
服务/守护层                          │
  LockService ── 拆分 ──► TimerManager(亮屏计时/对账/到期闹钟)
                       ├─ LockGuard(watchdog 拉回锁屏 + 无障碍自愈)
                       └─ LockOverlayManager(全屏悬浮窗覆盖)
  BootReceiver / AlarmReceiver / RecoveryAccessibilityService(无障碍守护)
        │
出题子系统 (question/)
  QuestionEngine ──调度──► QuestionProvider[]
        ├─ BankProvider(题库型): PinyinProvider / EnglishProvider / CituProvider
        ├─ MathProvider + MathSpec(代码生成型)
        ├─ DistractorSampler(干扰项采样)  RecentQuestionQueue(防重复)
        └─ QuestionUi(共用渲染器)
  BankRepository ── BankSource 责任链 ──► CustomBankSource(L0) → AssetBankSource(L1/L2) → BuiltinBankSource(L3)
        └─ CustomBankStore(自定义文件读写)
  Subject / Grade / BankEntry / Question(值对象)
        │
持久化
  PrefManager(SharedPreferences): 配置 / PIN(PBKDF2) / 计时对账 / 正确率 / 一次性迁移
```

### 5.2 核心模块说明

- **`TimerManager`**：基于 `SystemClock.elapsedRealtime()`（单调递增，与墙钟无关）的亮屏计时；每 1s 递减、每 5 tick 持久化；注册 `SCREEN_OFF/ON` 广播实现熄屏暂停；到期用 `AlarmManager.setExactAndAllowWhileIdle` 唤醒（被拒时降级 `setAndAllowWhileIdle`）。
- **`LockGuard`**：每 800ms 检查 `LockScreenActivity.isOnTop()`，不在前台则回调拉起；每 15s 检查无障碍守护是否启用，未启用则 `RecoveryAccessibilityService.trySelfEnable` 自愈。
- **`LockOverlayManager`**：`TYPE_APPLICATION_OVERLAY` 全屏 `FrameLayout`，拦截点击/OK/方向键，回退到锁屏；无悬浮窗权限时跳过（小米电视等靠它兜底）。
- **`QuestionEngine`**：`create()` 先按 `provider.isAvailable(grade)` 过滤科目，再以"有效科目集"算题量顺序表；全不可用则强制回退 `PinyinProvider`（守住"永不 null"契约）。`nextQuestion()` 经 `RecentQuestionQueue`（容量 10）防重复；`nextPreviewQuestion()` 不进队列。
- **`BankSource` 责任链**：`BankRepository` 按 `priority()` 升序（Custom=0 → Asset=1 → Builtin=3）遍历，首个 `usable()`（条目≥4）即返回；失败透明回退，绝不抛空。
- **`DistractorSampler`**：同池取 3 个不同值 + 正确项洗牌 = 4 选项，文本互异，绝不占位。
- **`PrefManager`**：PIN 用 **PBKDF2**（含随机盐，旧 SHA-256 明文自动升级）；计时对账三枚时间戳；累计正确率（total=0 时返回 -1）。

### 5.3 关键实现思路

1. **计时防绕过（核心难点）**：放弃墙钟，改用 `elapsedRealtime` 单调时钟 + 熄屏暂停 + uptime 差值对账 + 跨重启 `UsageStats` 补扣；三重守护（HOME alias / 悬浮窗 / 无障碍）互为兜底。改动此区域需极度谨慎。
2. **永不无题可出**：`BankSource` 三级兜底（自定义→本年级 assets→相邻年级→内置 144 条）+ 数学代码生成，保证 `QuestionEngine.nextQuestion()` 不可能返回 null。
3. **干扰项质量**：集中到 `DistractorSampler`，单测覆盖退化场景（题数 < 科目数）。
4. **预览隔离**：预览用独立引擎实例 + `nextPreviewQuestion()`，不污染正式防重复队列与正确率统计。
5. **默认值迁移**：`legacy_defaults_migrated` 一次性标志，避免每次启动重置家长设置（五年级/仅拼音 → 三年级/拼音+数学）。
6. **构建期资产校验**：`verifyQuestionBanks` 在 `preBuild` 强制校验题库完整性，作为冒烟测试。

- **权限必做**：自启动、悬浮窗、省电白名单、使用情况访问（对账补扣）
- **日志标签**：计时/守护 `LockService`；题库 `KidsLock-Question`

### 6.5 交接必读（关键纪律）

1. **禁改清单（防绕过核心）**：`LockService` / `RecoveryAccessibilityService` / `BootReceiver` / `AlarmReceiver` 及 `PrefManager` 的计时对账逻辑，改动需评审；牵一发动全身。
2. **改默认值/规则要全链路同步**：PRD、`docs/设计-多科目分级题库.md`、`README.md`、代码注释中的年级/科目/题数默认值必须一致（曾出现多处残留旧值自相矛盾）。
3. **改 Kotlin 后必实跑 `assembleDebug --offline`**：新增集合类等极易漏 import，肉眼审不出（历史踩坑）。
4. **题库资产改动会触发 `verifyQuestionBanks`**：确保条目数/去重/空字段达标，且 `pinyin_5.json` 与 `BuiltinPinyinBank.kt` 一致。
5. **密钥库不在仓库**：release 签名经环境变量/CI Secret；切勿把 `.keystore` 提交入库。
6. **JDK 必须用 17**：系统若装了 21/25 会构建失败，用仓库内 `.workbuddy/tools/jdk17` 或显式指定。
7. **出题数量规则**：N>5 时单科上限 `⌈N/M⌉`（数学、英语各自 ≤ cap；拼音+语文合计 ≤ cap）；N=5 不设上限；上限永不突破。逻辑见 `QuestionEngine.buildSchedule` 与 `verify_schedule.py`（45 场景）。

## 7. 在第三方工具中无缝继续开发的建议

- **直接 clone 即可构建**：远端已是干净可编译状态（本机已验证 `BUILD SUCCESSFUL`）。第三方工具只需提供 JDK17 + Android SDK 路径。

- **Gradle 缓存**：在 `~/.gradle`（约 500M+），离线构建需一并保留或首构建联网。
